# NauticMixxx 1.9.0 — USB browser and performance GRID

- SOURCE shows NO DEVICE when empty, and USB1, USB2, etc. for connected exports. Slot labels stay stable while devices remain connected and do not use volume names.
- USB entry immediately shows the first category's contents. ARTIST, ALBUM, TRACK, KEY, PLAYLIST, HISTORY, MATCHING and FOLDER precede additional exported categories.
- Category previews use two browse columns. PLAYLIST shows folders/playlists and their track titles; the expanded playlist track view retains its waveform, title, artist, BPM and genre columns.
- Controller rotation previews categories in blue. Pressing ENTER or touching a category transfers selection to its adjacent list and leaves the category gray. BACK returns through folder and category levels.
- ARTIST previews albums; ALBUM and HISTORY preview tracks. KEY includes a RELATED KEY column reserved for a future release.
- MATCHING lists DECK 1 and DECK 2 and uses NauticMixxx harmonic compatibility plus a six-percent BPM window. These are computed suggestions, not imported Rekordbox saved matching pairs.
- FOLDER browses directories and supported audio files on the selected USB, including files outside the export. These tracks stay temporary, can be analyzed for playback, and cannot be imported, persisted or written back as metadata.
- SEARCH includes a touch keyboard with letters, numbers, backspace, CLEAR and SPACE. Results use a compact track list beside INFO. An empty query shows no results.
- Track lists fit twelve complete rows. Sidebar buttons fill the same browse height without a small scrollbar.
- DECK badges move slightly downward for vertical centering.
- Physical controller and touchscreen validation remains pending. New profiles default to English. All packages use the NauticMixxx icon. macOS uses an ad-hoc signature and is not Apple-notarized.

- Performance interaction selects a deck independently of playback MASTER and
  outlines that deck's waveform information and track card. Engine feedback
  does not change this selection.
- Holding Inpulse BROWSER for two seconds in PERFORMANCE toggles GRID. The
  encoder translates the selected grid; jogs select a deck without editing it.
  Only that deck's red downbeats span its waveform. GRID can also be toggled
  on the touchscreen.
- The selected GRID panel provides Snap Grid (CUE), Shift Grid, earlier/later
  half-beat shifts and Reset. Reset restores the grid captured on entering this
  editing session for that track; these temporary USB edits are not exported.
- Pad mode titles interrupt a centered horizontal rule. BEAT JUMP uses mirrored
  corner arrows and functional size-specific touch jump pads. Numeric performance
  readouts are bold; HOT CUE pad labels retain their regular weight.
- STATUS / BEAT FX framing, MASTER sizing and TEMPO spacing are refined. The
  six-percent pitch range uses #18FC00.
- Both fixed deck wave pairs blink together at an approximate 400 ms on/off
  cadence. This timing is not claimed as a measured Pioneer hardware cadence.
- The macOS RX3 window has no title bar and starts at a fixed 1280×800 size.
  Cmd+Q and the native application menu remain available.

- USB browse columns share a continuous gray divider, including their headers and blank rows. Left lists no longer reserve a black scrollbar gap; controller and touch scrolling remain available.
