# Seguridad

No publiques vulnerabilidades, certificados de firma ni datos personales en un
issue. Informa el problema de forma privada al propietario del repositorio de
GitHub mediante **Security → Report a vulnerability**.

Incluye versión, sistema operativo, pasos mínimos y, si existe, el hash del
archivo afectado. El objetivo es confirmar recepción en 7 días y publicar una
corrección coordinada cuando corresponda.

La rama mantenida es la última versión estable. Los binarios no notarizados no
deben presentarse como firmados por Apple; valida siempre `SHA256SUMS.txt`.
