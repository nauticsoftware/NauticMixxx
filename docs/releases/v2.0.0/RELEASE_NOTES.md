# NauticMixxx 2.0.0 — RX3 workflow, emergency playback and precise synchronization

- Integrate the existing TOOLS operations into UTILITY, grouped as DECK, MIXER, EFFECTS, BROWSER, RECORDING, DISPLAY and GENERAL. MENU and established controller gestures open the unified table. Use BROWSER’s black/gray rows and gray column divider; restore the selected row on submenu return. Remove hardware-only and unimplemented placeholder rows. Keep live shared settings and preview/apply/cancel editing, per-deck Auto Cue persistence and time-scale fallback when phrase data is absent. Replace the REMAIN font symbol with a scalable vector stopwatch.
- Add the separate SOURCE MY SETTINGS panel with LOAD, BACKGROUND COLOR and WAVEFORM COLOR. Expose SOURCE, BROWSE, TAG LIST, PLAYLIST, SEARCH and MENU in the BROWSE/SOURCE header; preserve the original PERFORMANCE topbar; use the highlighted SOURCE USB for navigation and settings loading. Keep controller gestures and SHORTCUT access unchanged. Save Nautic USB accents separately from rekordbox files.
- Remove the large TOOLS entry from the SOURCE device list; retain header/SHORTCUT access and make the existing BACK button selectable after the last action in every encoder tool menu.

- Preserve RX3 overview colors near track end and after completion by removing the red background and outline; retain playing-address blinking and all other end-warning behavior.

- Make SHORTCUT CLOSE reachable immediately after TOOLS with the browser encoder; a short press closes the panel and restores the underlying page.
- Keep a two-reference-pixel black gap between the main waveform lanes and the right-side Beat FX panel.

- Correct safe FILTER loading and REVERB signal send/decay control. Add exact ECHO/PHASER/TREMOLO X-PAD fractions, six-second ECHO storage and correct steady-delay read-head advancement. Allow held bank replacement and encoder-operated BEAT FX effect, intensity, routing, tempo and bank controls through SHORTCUT → UTILITY → EFFECTS, even without USB. Show the actual X-PAD value and advance one beat/pitch cell per encoder tick. Keep the full RX3 effect catalogs deferred.

- Add shared encoder-operated UTILITY actions for Tag List, four Playlist Bank favorites, combined Track Filter, Related Key, memory cues/loops, headphone preview, USB recording and available software audio paths. Preserve established controller gestures.
- Correct both Beat Loop tables and Gate Cue's paused/playing behavior. Add independent per-deck Release FX hold/latch processing and pad release ownership across SHIFT changes. Release FX audio still needs RX3 calibration; the 14 Beat FX and six Sound Color FX expansions remain deferred.
- Add explicit USB cue/loop/Active Loop/beatgrid saves, playlist creation and incremental session history with identity checks, recovery copies and atomic file replacement. Preserve unchanged imported timing and unknown source data. Recorder commands include guarded start/stop/manual split, elapsed time, USB capacity and source-removal handling.
- Add asynchronous MY SETTINGS SAVE, Auto Cue thresholds, SINGLE/CONTINUE and EJECT LOCK. Imported VINYL state now updates the Inpulse 500 jogs and lamps. Use native macOS filesystem inspection for actual volume identity, free space and write status.
- Add native two-band microphone EQ, optional low-cut and normal talkover with selectable dB attenuation through the shared encoder menu. Preserve other USB mixer settings when saving low-cut/talkover level; analog response and timing still need hardware calibration.
- These features are included in 2.0.0. Link Export, registered MATCHING pairs, microphone processing/routing parity and further controller/hardware validation remain unfinished. See [RX3 workflow scope](docs/RX3-WORKFLOW-2.0-EN.md).


- Select DECK 1 or 2 by touching its track title above the overview, touching its right-hand main waveform information card, or pressing its normal LOAD button in PERFORMANCE. LOAD in PERFORMANCE selects the deck without loading a track; LOAD in BROWSE retains normal loading. Jog, pitch, EQ, transport and pads no longer change deck selection.
- Fix VIEW returning briefly to PERFORMANCE and immediately reopening BROWSE. FLX6, FLX4 and shared Pioneer/Roland adapters now keep page-selection triggers latched; the skin clears the previous trigger itself. Add regression coverage for native RX3, legacy RX3 tabs and standard Mixxx skins.
- Hold BROWSER for two seconds in PERFORMANCE to enter GRID. Hold it in BROWSE to go BACK. Hold SHIFT + BROWSER for two seconds to open or close SHORTCUT. Release after a long press does not trigger another action. Dedicated hardware BACK buttons retain their navigation action.
- SHORTCUT follows the RX3 two-column layout, with touch controls, a one-pixel white encoder focus outline, live cyan option selection and persistent settings. Press the encoder to edit a row, turn to change its value, and press again to leave editing.
- Replace LCD brightness with JOG RESPONSE and per-deck PLAYBACK SETTINGS. Adjust scratch sensitivity, pitch bend, master tempo and tempo range. Add crossfader curves alongside channel fader curves, EQ/ISO, split/stereo monitoring, effect quantization and needle lock.
- MY SETTINGS: LOAD reads and validates rekordbox settings from the USB selected in SOURCE. Both decks must be paused. Supported settings are applied together; corrupt files cancel the import. DETAILS lists the result and unsupported hardware settings. The import never writes to the USB.
- HOT CUE AUTO LOAD supports ON, rekordbox track SETTING and OFF. New manual hot cues remain available when automatic recall is disabled. VINYL SPEED ADJUST controls the stop response of the normal controller PLAY button.
- Tempo range uses green for 6%, the existing red for 10%, white for 16%, and unboxed WIDE text in the A.HOT CUE accent. Range numerals and the percent symbol receive a one-pixel stroke.
- Remove the inactive deck card outline around its overview area; keep the white outline for the selected deck in PERFORMANCE and the compact browser footer.
- Match the supplied STATUS pad-strip reference across all eight modes on both decks: add eight reference pixels beneath the mode title, separate the two 18-pixel pad rows by ten pixels, and preserve the existing 70-pixel page and overview boundary.
- SHORTCUT uses a black background, consistent #007CE0 active buttons, standard button widths and the compact BROWSE footer. The panel stops above the shared footer's actual top edge after navigation and resizing, keeping deck captions, marks and borders fully visible. Opening the panel hides the performance page, including its native waveform surfaces, and closing it restores the prior page.
- Move the frameless RX3 window by dragging its empty top margin, limited to 10 pixels with side insets. REMAIN and all other controls retain their normal touch behavior; full-screen and maximized windows are excluded.
- Replace the three simultaneous effect selectors and FX UNIT button in BEAT FX with four persistent favorites. Keep the current Beat FX selected after momentary X-PAD release, independently of activation. Mark selected favorites and beat/pitch cells with a one-pixel white outline. Keep discrete cells neutral gray/white while held; reserve cyan feedback for the continuous X-PAD rail. Show Beat FX names in uppercase with slightly larger fonts in the Bank, its chooser and the RX3 selector. Empty slots appear as blank black rectangles and open their own effect chooser, even with another effect selected. Offer Echo, Reverb, Flanger, Phaser, Filter, Pitch Shift, Tremolo and Glitch in the Bank and RX3 selector; exclude utility/EQ processors such as Loudness. Recall a favorite with one touch and delete a chosen registration before reusing it. Old utility favorites open the curated chooser for individual repair; unavailable saved effects retain their slot until explicitly deleted. Choosing a different processor loads it disabled; registering the current processor preserves its activation and parameters.
- Refine the right-hand Beat FX panel against the supplied reference: full-width title, uniform black-field insets, centered uppercase effect name, fixed readout rows with small units, and explicit MASTER/STATUS/BEAT FX selected states.
- Replace the X-PAD's deck-loop commands with a continuous touch slider for the selected Beat FX. Touch enables the effect, release cancels it, and dragging changes its contextual parameter. Use delay/cycle, reverb bandwidth, filter cutoff or pitch when available; other processors use their exposed time/frequency parameter or first knob, falling back to a metaknob only when no knob is exposed. Keep engine quantization and update the time/parameter readout. STATUS/BEAT FX page selection alone leaves effect activation unchanged. Adapt the X-PAD to its processor: beat fractions for time, semitone cells for Pitch Shift, and a tapered rail with open arrows for continuous controls. The idle rail is gray, including when no effect is selected, with a darker gray center; touch alone highlights it in cyan until release or cancellation. Dim unavailable fractions rather than substituting another time.
- Touch the top REMAIN rail to open a standalone countdown timer with presets, six recent durations, HH:MM:SS numeric entry, minute adjustments, START/STOP and CLR. REMAIN returns to the waveform view without stopping the countdown; its white progress rail empties from right to left.

A playing deck repeats cached stereo audio without disk access, shows a red emergency label and the limited-functions message, blanks unavailable track/waveform data and freezes its transport. Loading a valid track clears the emergency state, including with LOAD LOCK active. A paused deck remains silent.
