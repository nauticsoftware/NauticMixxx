NAUTICMIXXX 1.2.0 FOR WINDOWS X64

Download NauticMixxx-1.2.0-Windows-x64-Setup.exe from the public GitHub release and run it directly. No ZIP extraction, BAT file, existing Mixxx installation or compiler is required.

The installer uses NSIS and installs NauticMixxx.exe to %LOCALAPPDATA%\Programs\NauticMixxx. The RX3 skin, controller mappings, effects and portable preset preferences are installed under %LOCALAPPDATA%\NauticMixxx. Existing profile values not managed by NauticMixxx are preserved and the previous configuration is backed up.

Select the Windows audio device and channel routing in Preferences > Sound Hardware. Check the controller, cue monitoring and USB drive before a live set. Uninstall through Windows Settings; personal profile data remains for safety.

This is a community build based on Mixxx 2.5.6. The EXE is unsigned and Windows SmartScreen may ask for confirmation.
